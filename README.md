# M-Restaurant Menu - Online Ordering System

## 🎉 Your Restaurant Website is Ready!

A professional restaurant website with online ordering via **WhatsApp** and **Email**.

### ✨ Features:
- 📱 Order via WhatsApp (Recommended)
- 📧 Order via Email (Backup)
- 🛒 Shopping Cart System
- 🚚 Delivery Option
- 🍽️ Dine-in Option
- 💳 Real-time Order Total
- 📱 Mobile Responsive

---

## 🚀 Quick Start

1. **Open `index.html`** in your browser to test
2. **Update your WhatsApp number** in `script.js` (line ~268)
3. **Upload to hosting** to make it live for customers
